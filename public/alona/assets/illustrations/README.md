# Reusable illustration crops

These PNG files are exact, native-resolution rectangular crops from the approved reference boards/panels. Each was inspected visually after cropping. Pixel coordinates below are `[x, y, width, height]` from the source image's top-left corner. Crops were copied at 1:1 size with Windows `System.Drawing`; they were not redrawn, stretched, color-adjusted, or re-compressed. Backgrounds and speech bubbles remain where they are part of the supplied illustration. Only approved European-context references are included.
